# Сайт платформы MoviBids — отдельный пакет к запуску

Лендинг на трёх языках (EN / RU / 中文) с двумя формами — «Запросить ставку» и «Стать поставщиком».
Каждая заявка уходит сразу в три канала: **почту, Telegram и Bitrix24**, а также сохраняется резервной копией в файл.

```
public/            — сам сайт (можно открыть index.html в браузере)
  config.js        — название бренда, юрлицо, контакты  ← менять здесь
  index.html       — лендинг
  privacy.html     — шаблон политики конфиденциальности (проверить с юристом)
  assets/          — стили, логотип, переводы (i18n.js), логика форм (app.js)
server/            — обработчик заявок + раздача сайта (Node.js 18+)
  server.js
  .env.example     — настройки каналов
```

## Название этой версии

1. `public/config.js` → `brand: "MoviBids"` — это имя подставляется в сайт, заголовки и тексты на трёх языках.
2. `server/.env` → `BRAND=MoviBids` — это имя используется в темах писем и заголовках лидов.
3. Логотип: заменить `public/assets/logo.svg` (сейчас это временный знак).

## Запуск

```bash
cd server
cp .env.example .env      # заполнить каналы
npm install
npm start                 # сайт на http://localhost:8080
```

Подойдёт любой VPS (Timeweb Cloud, Selectel, Яндекс Облако и т.п.) с Node.js 18+. Перед сервером — Nginx или Caddy с HTTPS, проксирующий на порт 8080.
Проверка, что сервер жив: `GET /healthz`.

## Настройка каналов заявок

| Канал | Что заполнить в `.env` | Где взять |
| --- | --- | --- |
| Почта | `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`, `LEADS_EMAIL_TO` | Настройки SMTP почтового провайдера (лучше отдельный ящик MoviBids, не личный) |
| Telegram | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Бот через @BotFather → добавить в чат команды → узнать chat id |
| Bitrix24 | `BITRIX24_WEBHOOK_URL` | Портал MoviBids → Разработчикам → Другое → Входящий вебхук с правами CRM. Заявка создаётся как лид (`crm.lead.add`) |

Пустой канал просто пропускается. Если все каналы недоступны, заявка всё равно сохраняется в `leads.jsonl`, а посетитель видит «Спасибо».

Защита: скрытое поле-ловушка для ботов, не больше 5 заявок с одного IP за 10 минут, ограничение размера запроса, проверка обязательных полей и согласия на обработку ПДн на сервере.

## Чек-лист перед запуском

- [ ] Окончательное название, проверка товарного знака и свободного домена (.com и ключевые зоны)
- [ ] Логотип вместо временного знака
- [ ] Юрлицо и реквизиты в `config.js`
- [ ] Политика конфиденциальности проверена юристом (`privacy.html`)
- [ ] Хранение ПДн граждан РФ: сервер или первичная запись данных в РФ (152-ФЗ, ч. 5 ст. 18)
- [ ] Уведомление Роскомнадзора об обработке ПДн
- [ ] Каналы заявок заполнены и протестированы (отправить по одной тестовой заявке)
- [ ] HTTPS-сертификат
- [ ] Аналитика (Яндекс Метрика / Google Analytics) и баннер о cookie, если аналитика ставит cookie
- [ ] Тексты RU и 中文 вычитаны носителями языка
- [ ] Цена Verified: сейчас «по запросу», комиссия Guaranteed 1–3% — подтвердить

## Чего на сайте сознательно нет

Выдуманных цифр, отзывов и логотипов клиентов. Их стоит добавить, когда появятся реальные сделки.
