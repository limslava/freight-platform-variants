# Брендовые варианты

Исходный сайт в корне проекта не изменён. Здесь лежат две автономные копии:

- `movibids/` — бренд в точном написании `MoviBids`;
- `frevigo/` — бренд в точном написании `FreVigo`.

В каждой копии отдельно настроены название на сайте, серверный fallback и пример `.env`. Запуск выполняется из соответствующей папки `server/` командой `npm start`.
